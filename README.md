# PROJECT EMBER

**PROJECT EMBER** is a community-developed launcher/client project for **Call of Duty: Black Ops III** on Windows.

This repository hosts the **public releases and automatic update files** for the EMBER Client.

## Download

Get the latest available build from the [Releases page](https://github.com/RealEragosBilal/EmberVersionUpdater/releases/latest).

1. Download `EMBER-Client.zip`.
2. Extract the archive into a folder.
3. Run `ember_client.exe`.

A legitimate copy of Call of Duty: Black Ops III is required.

## Automatic updates

EMBER checks this repository for newer stable releases. Update packages are validated using a manifest and SHA-256 checksums before installation.

Each updater release contains:

- `EMBER-Client.zip` — the client package
- `ember-manifest.json` — the file list and integrity checks

## Beta status

**EMBER is currently in public beta testing.** Features may change, and bugs or failed updates are possible. Keep a backup of your existing installation before updating.

Found an issue? Please report what happened, the EMBER version, and any relevant error messages through [GitHub Issues](https://github.com/RealEragosBilal/EmberVersionUpdater/issues).
